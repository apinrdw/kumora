# Order book radar scanner: PROTOTYPE, never merge

Throwaway prototype for [How the scanner looks and ranks](https://github.com/apinrdw/kumora/issues/493), map [#485](https://github.com/apinrdw/kumora/issues/485). Published as https://claude.ai/artifact/V9pUkw2ayyHp8Jj87m4E7T (Version 3).

`order-book-radar.html` is one static page on simulated books, events and alerts. Open it in a browser and switch variants with ◀ ▶ or the arrow keys:

- `#table`: A, ranked table
- `#tug`: B, tug of war
- `#tiles`: C, tiles plus event feed
- `#tug-feed`: D, tug of war plus event feed
- `#tiles-split`: E, split tiles plus event feed (**the owner's pick**, 2026-11-18)

`scanner-e-split-tiles.png` is E at 1600×1000.
