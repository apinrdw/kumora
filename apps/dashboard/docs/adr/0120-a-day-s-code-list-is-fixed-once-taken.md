# A day's code list is fixed once taken

A day past taking ingest (`takesIngest`) takes nothing more, but one with no code list takes the relay's first. Its 404 was never cached (`no-store`), so no immutable answer changes, and a day whose list missed the seal stays searchable. A list once taken stays fixed.
