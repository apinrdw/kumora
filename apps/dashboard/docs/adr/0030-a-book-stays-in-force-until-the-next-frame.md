# A book stays in force until the next frame

A book stays in force until the next frame, so a minute with no frame keeps the book before it, and the day's last book holds to the end of streaming hours (`streamingEndOf`), since no frame could replace it after. No heatmap slice starts from there on, in the GET's answer or on the page.
