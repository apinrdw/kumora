# The recorded day path carries the viewer protocol version

The browser caches a sealed day's answer for a year by its whole URL, so the recorded day path carries the viewer protocol's version: an answer cached before footprints rode with the candles is then never reused. The query is ignored when read, so an older build's tab still loads.
